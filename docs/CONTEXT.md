# EmaraLeague — Project Context

## Goal
Build **EmaraLeague**, a premium Minecraft tournament & events engine plugin for Paper 1.21.x+. It allows server owners to create and run competitive tournaments across any minigame mode (PvP, PvE, speedrun, etc.) with automated brackets, matchmaking, spectator tools, and monetized add-ons. Target worldwide sales on BuiltByBit, SpigotMC, Polymart, and a direct website.

## Users
1. **Server owners** — small-to-medium Minecraft servers who want to run events without custom development.
2. **Network admins** — multi-server networks needing scalable cross-server tournaments.
3. **Content creators** — running viewer/viewer-participation events on their servers.
