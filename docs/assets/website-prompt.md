## 📝 How to Use

1. Copy the prompt above
2. Use Midjourney for cinematic quality
3. Add "--ar 16:9" for hero, "--ar 4:3" for features
4. Generate at highest resolution
5. Optimize for web (compress)

## 💡 Pro Tips
