## 📸 SCREENSHOTS (7 Required)

### Screenshot 1: Arena Setup
**What to show:** Arena with center and lobby markers, scoreboard visible

**How to create:**
1. Create arena: `/el arena create MyArena`
2. Set center: `/el arena setcenter MyArena` (stand in middle)
3. Set lobby: `/el arena setlobby MyArena` (stand at entrance)
4. Start match to show scoreboard
5. Screenshot from above (F5 mode) or spectator view
6. Edit: Add border, text overlay "EmaraLeague Arena Setup"

**Tools:** Minecraft + OBS/Screenshot tool + Photoshop/GIMP/Canva

---

### Screenshot 2: Tournament Creation
**What to show:** Chat with `/el create SummerCup duels` command

**How to create:**
1. Type `/el create SummerCup duels` in chat
2. Screenshot with chat visible (F1 to show chat)
3. Edit: Highlight command with box, add text "Create Tournament"

---

### Screenshot 3: Countdown
**What to show:** BossBar countdown with "3..." title

**How to create:**
1. Start tournament: `/el start SummerCup`
2. Screenshot during countdown (when BossBar shows)
3. Edit: Add arrow pointing to BossBar, text "10-Second Countdown"

---

### Screenshot 4: In-Match Scoreboard
**What to show:** Scoreboard with teams, players, kills, timer

**How to create:**
1. Match in progress
2. Screenshot with scoreboard visible (right side)
3. Edit: Highlight scoreboard with box, text "Live Scoreboard"

---

### Screenshot 5: Victory Announcement
**What to show:** "VICTORY!" title with team name

**How to create:**
1. End match with winner
2. Screenshot when victory title shows
3. Edit: Add text "Tournament Winner"

---

### Screenshot 6: Team Selection
**What to show:** `/el team list SummerCup` output

**How to create:**
1. Type `/el team list SummerCup`
2. Screenshot with chat output
3. Edit: Highlight team names, text "Team Management"

---

### Screenshot 7: Configuration File
**What to show:** config.yml with syntax highlighting

**How to create:**
1. Open config.yml in VS Code or text editor
2. Screenshot with syntax highlighting
3. Edit: Highlight key settings, text "Fully Configurable"

## 🎥 DEMO VIDEO (2-3 minutes)

### Video Structure

| Time | Scene | Content |
|------|-------|---------|
| 0:00-0:10 | Intro | Logo + "EmaraLeague — Premium Tournament Engine" |
| 0:10-0:25 | Setup | Create arena, set center, set lobby |
| 0:25-0:40 | Create | Create tournament, players join |
| 0:40-1:00 | Countdown | BossBar countdown, title announcements |
| 1:00-1:30 | Match | Players fighting, scoreboard visible |
| 1:30-1:45 | Victory | Winner announcement, teleport back |
| 1:45-2:00 | Features | Quick overview of 3 game modes |
| 2:00-2:15 | Outro | "Available on BuiltByBit — $19.99" |

### Recording Tips

**Equipment:**
- **Recording:** OBS Studio (free)
- **Editing:** DaVinci Resolve (free) or Premiere Pro
- **Thumbnail:** Canva (free) or Photoshop

**Settings:**
- Resolution: 1920x1080 (1080p)
- FPS: 60fps (smooth gameplay)
- Bitrate: 10-15 Mbps (high quality)

**Recording Checklist:**
- [ ] Clean desktop (no distractions)
- [ ] Good lighting (bright, clear)
- [ ] No lag (stable FPS)
- [ ] Audio commentary (optional but recommended)
- [ ] Show all key features
